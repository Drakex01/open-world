Documentation

Welcome to the official developer documentation for CYBERSPACE. Here you will find everything you need to customize your dashboard, build new widget panels, and integrate external APIs.

Quick Start

To run the CYBERSPACE development environment locally, ensure you have Node.js installed, then execute:

npm install
npm run dev

Adding a Custom Panel

Panels in CYBERSPACE are modular components registered via src/config/panels.ts. You can create a new panel by implementing the PanelComponent interface.

API Rate Limits

By default, CYBERSPACE proxies requests through a local Redis cache to prevent rate-limiting against public APIs. Ensure your LOCAL_API_MODE is configured correctly in your .env file to enable graceful fallbacks.
